# Blockchain Crowdfunding Platform

Децентрализованная краудфандинговая платформа, построенная на базе смарт-контрактов Ethereum. Проект позволяет пользователям создавать кампании по сбору средств, делать пожертвования и получать за это специальные токены вознаграждения (Reward Tokens). Также реализована система голосования для участников.

## Основной функционал

* Создание кампаний: возможность задать цель (goal) и продолжительность (duration) сбора средств.
* Пожертвования (Contributions): пользователи могут отправлять средства в кампанию и автоматически получать Reward Tokens пропорционально пожертвованной сумме.
* Завершение кампаний: если цель достигнута, создатель может забрать собранные средства за вычетом комиссии платформы (Platform Fee).
* Возвраты (Refunds): если кампания не достигла заявленной цели до окончания срока, инвесторы могут вернуть свои вложенные средства.
* Система голосования: создатели успешных кампаний могут инициировать голосования, а участники могут голосовать (за или против). Вес голоса определяется балансом токенов вознаграждения (Reward Tokens).

## Стек технологий

* Смарт-контракты: Solidity, OpenZeppelin Contracts
* Среда разработки: Hardhat
* Фронтенд: HTML, CSS, Vanilla JavaScript

## Структура проекта

* `contracts/` - исходный код смарт-контрактов (`Crowdfunding.sol`, `RewardToken.sol`).
* `frontend/` - клиентская часть приложения (включает логику для разных ролей: создателей/инженеров и пользователей).
* `scripts/` - скрипты для развертывания (деплоя) смарт-контрактов.
* `test/` - директория для написания и хранения тестов для смарт-контрактов.

## Установка и запуск (локальная среда)

1. Установите зависимости проекта:
   ```bash
   npm install
   ```

2. Скомпилируйте смарт-контракты:
   ```bash
   npx hardhat compile
   ```

3. Запустите локальную блокчейн-сеть Hardhat:
   ```bash
   npx hardhat node
   ```

4. В новом окне терминала разверните смарт-контракты в локальной сети:
   ```bash
   npx hardhat run scripts/deploy.js --network localhost
   ```

5. Настройка фронтенда:
   После развертывания контрактов скопируйте полученные адреса `RewardToken` и `Crowdfunding` из консоли и обновите их в соответствующих файлах фронтенда (например, в `wallet.js` или других `.js` файлах), чтобы интерфейс мог взаимодействовать с правильными контрактами. Не забудьте также обновить ABI контрактов при внесении изменений в Solidity-код.

6. Запуск фронтенда:
   Откройте файл `frontend/index.html` в браузере напрямую или используйте локальный сервер (например, расширение Live Server в VS Code, или команду `npx serve frontend`).
